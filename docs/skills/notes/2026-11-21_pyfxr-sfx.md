# pyfxr — sfxr uslubidagi protsedurali multfilm SFX (Python)
Manba: https://github.com/lordmauve/pyfxr — HEAD 902b8a2; PyPI `pyfxr` 0.3.0 (2022-04-21), BSD-3-Clause (c) 2021 Daniel Pope.
Linux wheel'lar cp36…cp313 (bizning Python 3.11 ga mos). Tekshirildi: 2026-11-21 (README, docs/*.rst, LICENSE o'qildi; o'rnatilmadi).

## Nima
Dr. Petter'ning klassik sfxr generatorining Cython porti. Tayyor tasodifiy presetlar: pickup (tanga olish),
powerup, jump, hurt, laser, explosion, select; to'liq parametrli `SFX` klassi; wavetable `tone()` va ADSR.
Natija `SoundBuffer` — 44.1 kHz mono, 16-bit butun son; buffer protokoli bor (numpy ga o'tkazish mumkin), `.save("x.wav")`.
Tarmoq, kalit, akkaunt yo'q.

## Nega bizga
Bizda allaqachon ~20 ta qo'lda yozilgan sfx (engine/make_video.py `sfx_*`) va lemo sfx.py bor. pyfxr ularni
ALMASHTIRMAYDI — Buck (tanga qahramon) uchun "8-bit / o'yin" ovozlari palitrasini kengaytiradi: tanga yig'ilishi,
"level up" (yutuq/tejash), "hurt" (pul yo'qotish), "select" (ro'yxat bandi). Har biri seed bilan qayta tiklanadigan.

## Qo'llash bosqichlari
1. `pip install pyfxr==0.3.0` (GUI siz; `[gui]` kerak emas).
2. `engine/sfx_fxr.py` (o'zimiz yozamiz): preset -> `np.frombuffer(memoryview(buf), np.int16)/32768` -> 48 kHz ga
   resample (scipy `resample_poly(x, 160, 147)`) -> float32. Seed/parametrlarni dict sifatida saqlang (kesh).
3. `mix_sfx()` ga yangi nomlar: `fxr_pickup`, `fxr_powerup`, `fxr_hurt`, `fxr_select` — mavjud sfx bilan bir xil
   gain/pan/duck yo'lidan o'tsin (−5 dB ducking va oxirgi −14 LUFS master o'zgarmaydi).
4. Avval 8–10 variant generatsiya qilib, tinglab, yaxshilarining parametrlarini spec presetiga muhrlang
   (har renderda tasodifiy emas).
5. QC: 1 Short da 2–3 joyda sinab, eski sfx bilan solishtiring; jurnalga yozing.
